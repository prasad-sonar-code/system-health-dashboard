# 📊 System Health Dashboard

A real-time system monitoring dashboard built with Python Flask and psutil. 
Shows live CPU, Memory, Disk, and Network stats — refreshes every 3 seconds automatically.

## 📸 Preview

![Dashboard](screenshots/dashboard.png)

## 🚀 Features

- Real-time CPU usage monitoring
- Memory usage with GB breakdown
- Disk usage with GB breakdown  
- Network I/O (sent/received in MB)
- Auto-refreshes every 3 seconds
- Beautiful dark theme UI

## 🛠️ Tech Stack

- Python 3
- Flask (web framework)
- psutil (system stats library)
- HTML/CSS/JavaScript (frontend)

## ⚙️ Setup & Run

```bash
# Install dependencies
pip install flask psutil

# Run the app
python3 app.py

# Open in browser
http://localhost:8080
```
